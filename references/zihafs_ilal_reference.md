# مرجع الزحافات والعلل في العروض العربي (Zihaf & 'Ilal Reference)

الزحافات والعلل هي التغيرات الصوتية والإيقاعية التي تلحق التفاعيل الشعرية الأصلية. تُميِّز مكتبة `pyarud` بدقة رياضية متناهية بين جميع هذه التغيرات وتُقيِّم تكلفة كل زحاف لاختيار أدق وزن شعري.

---

## 1. الفرق الجوهري بين الزحاف والعلة

| وجه المقارنة | الزحاف (الزحافات) | العلة (العلل) |
| :--- | :--- | :--- |
| **موضع الحدوث** | يدخل ثواني الأسباب (الحشو، العروض، والضرب) | تدخل الأوتاد والأسباب في العروض والضرب خاصة |
| **طبيعة الحرف المستهدف** | يختص بثواني الأسباب فقط | يلحق الأوتاد والأسباب معاً |
| **حكم الالتزام (اللزوم)** | غير لازم (جائز)؛ إذا ورد في بيت لا يلزم في باقي القصيدة | لازمة؛ إذا استعملها الشاعر في أول بيت التزمها في كل القصيدة |
| **النوع** | مفرد أو مركب (مزدوج) | علل زيادة (في المجزوء) أو علل نقص |

---

## 2. الزحاف المفرد (Single Zihafs)
هو التغيير الذي يلحق حرفاً واحداً في التفعيلة:

| الاسم العربي | الاسم الإنجليزي | تعريفه الدقيق | التغيير الثنائي | التفعيلة المتأثرة والمتحولة |
| :--- | :--- | :--- | :--- | :--- |
| **الإِضْمَار** | **Idmar** | تسكين الثاني المتحرك | `11...` $\to$ `10...` | `متفاعلن` (`1110110`) $\to$ `متْفاعلن` (`1010110` / `مستفعلن`) |
| **الْخَبْن** | **Khaban** | حذف الثاني الساكن | `10...` $\to$ `1...` | `فاعلن` (`10110`) $\to$ `فعلن` (`11010`)<br>`مستفعلن` (`1010110`) $\to$ `متفعلن` (`110110`)<br>`فاعلاتن` (`1011010`) $\to$ `فعلاتن` (`1101010`) |
| **الْوَقْص** | **Waqas** | حذف الثاني المتحرك | `11...` $\to$ `1...` | `متفاعلن` (`1110110`) $\to$ `مفاعلن` (`110110`) |
| **الطَّي** | **Tay** | حذف الرابع الساكن | `...10...` $\to$ `...1...` | `مستفعلن` (`1010110`) $\to$ `مستعلن` (`101110` / `مفتعلن`)<br>`مفعولات` (`1010101`) $\to$ `مفعلات` (`101101` / `فاعلات`) |
| **الْعَصْب** | **Asab** | تسكين الخامس المتحرك | `...11...` $\to$ `...10...` | `مفاعلتن` (`1101110`) $\to$ `مفاعَلْتن` (`1101010` / `مفاعيلن`) |
| **الْقَبْض** | **Qabadh** | حذف الخامس الساكن | `...10...` $\to$ `...1...` | `فعولن` (`11010`) $\to$ `فعول` (`1101`)<br>`مفاعيلن` (`1101010`) $\to$ `مفاعلن` (`110110`) |
| **الْعَقْل** | **Akal** | حذف الخامس المتحرك | `...11...` $\to$ `...1...` | `مفاعلتن` (`1101110`) $\to$ `مفاعتن` (`11010` / `فعولن`) |
| **الْكَف** | **Kaff** | حذف السابع الساكن | `...10` $\to$ `...1` | `فاعلاتن` (`1011010`) $\to$ `فاعلات` (`101101`)<br>`مفاعيلن` (`1101010`) $\to$ `مفاعيل` (`110101`)<br>`مستفع لن` (`1010110`) $\to$ `مستفع ل` (`101011`) |

## 3. الزحاف المزدوج / المركب (Double Zihafs)
هو اجتماع زحافين مفردين في تفعيلة واحدة:

| الاسم العربي | الاسم الإنجليزي | التركيب | التغيير الثنائي والتفعيلة الناتجة |
| :--- | :--- | :--- | :--- |
| **الْخَبْل** | **Khabal** | خبن + طي (حذف الثاني والرابع الساكنين) | `مستفعلن` (`1010110`) $\to$ `مَتَعِلُنْ` (`111110` / `فَعِلاتُنْ`) |
| **الْخَزْل** | **Khazal** | إضمار + طي (تسكين الثاني وحذف الرابع) | `متفاعلن` (`1110110`) $\to$ `مُتْفَعِلُنْ` (`101110` / `مُفْتَعِلُنْ`) |
| **الشَّكْل** | **Shakal** | خبن + كف (حذف الثاني والسابع الساكنين) | `فاعلاتن` (`1011010`) $\to$ `فَعِلاتُ` (`110101`) |
| **النَّقْص** | **Nakas** | عصب + كف (تسكين الخامس وحذف السابع) | `مفاعلتن` (`1101110`) $\to$ `مُفَاعَلْتُ` (`110101` / `مَفَاعِيلُ`) |

---

## 4. علل الزيادة (Ellal of Increase)
تدخل الأعاريض والضروب في البحور المجزوءة لزيادة نغمتها:

| العلة | بالإنجليزية | تعريفها | النتيجة |
| :--- | :--- | :--- | :--- |
| **التَّرْفِيل** | **Tarfeel** | زيادة سبب خفيف (`10`) على ما آخره وتد مجموع | `فاعلن` (`10110`) $\to$ `فاعلاتن` (`1011010`)<br>`متفاعلن` (`1110110`) $\to$ `متفاعلاتن` (`111011010`) |
| **التَّذْيِيل** | **Tatheel** | زيادة حرف ساكن على ما آخره وتد مجموع | `فاعلن` (`10110`) $\to$ `فاعلانْ` (`101100`)<br>`مستفعلن` (`1010110`) $\to$ `مستفعلانْ` (`10101100`)<br>`متفاعلن` (`1110110`) $\to$ `متفاعلانْ` (`11101100`) |
| **التَّسْبِيغ** | **Tasbeegh** | زيادة حرف ساكن على ما آخره سبب خفيف | `فاعلاتن` (`1011010`) $\to$ `فاعلاتانْ` (`10110100`) |

---

## 5. علل النقص (Ellal of Decrease)
تدخل الأعاريض والضروب بحذف جزء من التفعيلة:

| العلة | بالإنجليزية | تعريفها | التغيير والتفعيلة |
| :--- | :--- | :--- | :--- |
| **الْحَذْف** | **Hadhf** | إسقاط السبب الخفيف من آخر التفعيلة | `فعولن` (`11010`) $\to$ `فعو` (`110`)<br>`مفاعيلن` (`1101010`) $\to$ `مفاعي` (`11010` / `فعولن`)<br>`فاعلاتن` (`1011010`) $\to$ `فاعلا` (`10110` / `فاعلن`) |
| **الْقَطْف** | **Qataf** | حذف السبب الخفيف + تسكين الخامس (حذف + عصب) | `مفاعلتن` (`1101110`) $\to$ `مفاعلْ` (`11010` / `فعولن`) (لازم في عروض الوافر التام) |
| **الْقَطْع** | **Qataa** | حذف ساكن الوتد المجموع وتسكين ما قبله | `فاعلن` (`10110`) $\to$ `فاعلْ` (`1010` / `فعلن`)<br>`مستفعلن` (`1010110`) $\to$ `مستفعلْ` (`101010` / `مفعولن`)<br>`متفاعلن` (`1110110`) $\to$ `متفاعلْ` (`111010` / `فعلاتن`) |
| **الْبَتْر** | **Batr** | اجتماع الحذف مع القطع | `فعولن` (`11010`) $\to$ `فَعْ` (`10`)<br>`فاعلاتن` (`1011010`) $\to$ `فاعِلْ` (`1010` / `فَعْلُنْ`) |
| **الْقَصْر** | **Qasar** | حذف ساكن السبب الخفيف وتسكين متحركه | `فاعلاتن` (`1011010`) $\to$ `فاعلاتْ` (`101100`)<br>`فعولن` (`11010`) $\to$ `فعولْ` (`11010` ساكن اللام) |
| **الْحَذَذ** | **Hathath** | إسقاط الوتد المجموع كاملاً من آخر التفعيلة | `متفاعلن` (`1110110`) $\to$ `مُتَفا` (`1110` / `فَعِلُنْ`) |
| **الصَّلْم** | **Salam** | إسقاط الوتد المفروق كاملاً من آخر التفعيلة | `مفعولات` (`1010101`) $\to$ `مَفْعُو` (`1010` / `فَعْلُنْ`) |
| **الْكَشْف / الكَسْف** | **Kasf** | حذف سابع الوتد المفروق المتحرك | `مفعولاتُ` (`1010101`) $\to$ `مفعولا` (`101010` / `مفعولن`) |
| **الْوَقْف** | **Waqf** | تسكين سابع الوتد المفروق المتحرك | `مفعولاتُ` (`1010101`) $\to$ `مفعولاتْ` (`1010100`) |

## 6. جدول تكلفة الزحافات في محرك `pyarud` (Zihaf Cost Map)

يقوم محرك البحث في `pyarud` بتفضيل التفاعيل السالمة والتغييرات الشائعة عبر نظام تكلفة دقيق:

```python
ZIHAF_COST_MAP = {
    # السالمة (Salim) - تكلفة صفرية
    "سالمة": 0.0,
    "صحيحة": 0.0,

    # التغييرات الطبيعية الشائعة جداً (Very Common)
    "مخبونة": 0.05,     # الخبن (Khaban)
    "مقبوضة": 0.05,     # القبض (Qabadh)
    "مضمرة": 0.05,      # الإضمار (Idmar)
    "معصوبة": 0.05,     # العصب (Asab)
    "مقطوعة": 0.08,     # القطع (Qataa)
    "محذوفة": 0.08,     # الحذف (Hadhf)
    "مقطوفة": 0.08,     # القطف (Qataf)

    # التغييرات متوسطة الشيوع
    "مطوية": 0.12,      # الطي (Tay)
    "مكفوفة": 0.15,     # الكف (Kaff)
    "مقصورة": 0.15,     # القصر (Qasar)
    "مذيلة": 0.15,      # التذييل (Tatheel)
    "مرفلة": 0.15,      # الترفيل (Tarfeel)

    # التغييرات المزدوجة النادرة (Double / Rare)
    "مخبولة": 0.25,     # الخبل (Khabal)
    "مخزولة": 0.25,     # الخزل (Khazal)
    "مشكولة": 0.25,     # الشكل (Shakal)
    "منقوصة": 0.25,     # النقص (Nakas)
    "مبتورة": 0.30,     # البتر (Batr)
    "حذاء": 0.30,       # الحذذ (Hathath)
    "صلماء": 0.30,      # الصلم (Salam)
}
```
يضمن هذا التدرج الرياضي عدم الخلط بين البحور المتشابهة (مثل الرجز والكامل، أو الهزج والوافر المعصوب).
